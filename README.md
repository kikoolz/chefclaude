# Chef Claude

Chef Claude is a small React app that helps users turn a list of ingredients into a recipe suggestion generated by an AI model. Users add ingredients one by one, and once they have enough items, the app sends the list to Hugging Face Inference Providers and renders the response as Markdown.

## Overview

The app is built with React and Vite. It keeps the UI intentionally simple:

- Add ingredients through a form
- Display the running ingredient list
- Enable recipe generation once the list is long enough
- Render the generated recipe in Markdown

## Features

- Clean single-page React interface
- Ingredient collection with basic input validation
- AI-generated recipe suggestions based on available ingredients
- Markdown rendering for readable recipe output
- Hugging Face router integration with fallback across multiple models
- Local Vite proxy so the browser calls `/api/huggingface/...` during development

## Tech Stack

- React 19
- Vite 6
- React Markdown
- Hugging Face Inference Providers via `router.huggingface.co`
- ESLint

## How It Works

1. The user types ingredients into the form.
2. Ingredients are stored in local React state.
3. After more than three ingredients are added, the app shows a `Get a recipe` action.
4. The app sends the ingredient list and a system prompt to Hugging Face chat completions.
5. The returned Markdown is rendered into the UI.

The AI request logic lives in `src/components/ai.js`. It currently tries these models in order:

- `meta-llama/Llama-3.1-8B-Instruct`
- `deepseek-ai/DeepSeek-V3-0324`
- `Qwen/Qwen2.5-7B-Instruct-1M`

This fallback exists because model availability depends on which Hugging Face providers are enabled for the token being used.

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Create your environment file

Add a `.env` file in the project root with:

```env
VITE_HF_API_KEY=your_hugging_face_token_here
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Environment Notes

This project expects a valid Hugging Face token in `VITE_HF_API_KEY`.

Important details:

- The development server proxies `/api/huggingface` to `https://router.huggingface.co`
- The app uses the OpenAI-compatible `v1/chat/completions` route on the Hugging Face router
- Some models may return provider-related errors if your Hugging Face account does not have a compatible provider enabled

If recipe generation fails with a message similar to:

`The requested model '...' is not supported by any provider you have enabled`

the code is working, but your token or provider configuration needs to support at least one of the configured models.

## Development Notes

- Recipe output is rendered with `react-markdown`
- The request layer handles both JSON and plain-text error responses from Hugging Face
- The current UI only shows the recipe button after the user has added more than three ingredients
- Errors are returned as readable strings and shown in the recipe output area
